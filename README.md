# TaskFlow Pro

A modern and responsive task management dashboard designed for planning, tracking, and organizing project work efficiently. This project showcases a clean project management interface with a sidebar navigation, KPI cards, and a kanban-style task board.

## Overview

TaskFlow Pro is a front-end project focused on productivity and workflow visibility. It helps teams manage projects by presenting tasks in a structured board view with status tracking, progress indicators, and project insights.

## Features

- Clean project dashboard layout
- Sidebar navigation for main sections
- Project overview summary cards
- Task status tracking across multiple columns
- Kanban board for To Do, In Progress, and Completed tasks
- Responsive design for desktop and smaller screens
- Professional styling using modern CSS design patterns

## Tech Stack

| Technology | Purpose |
| --- | --- |
| HTML5 | Page structure and content layout |
| CSS3 | Styling, layout, colors, responsiveness |
| Font Icons / Emoji | Visual indicators for tasks and actions |

## Getting Started

1. Download or clone the project files.
2. Open the project folder in your preferred code editor.
3. Launch `index.html` in your browser.

No additional installation or build process is required because this is a static front-end project.

## Usage

- Use the sidebar to navigate between project sections.
- Review the summary cards to understand overall project activity.
- Track tasks using the kanban board layout.
- Monitor task progress and priorities visually.

## Customization

You can easily customize the project by:

- changing project names and labels in `index.html`
- updating colors, spacing, and layout in `style.css`
- modifying task titles, priorities, and team assignments to match your workflow
